Variable is a name storage location that stores a value in python.
Example : 
name = "irfan"  #string
age = 18  #integer
score = 92.6  #float

Method is a function that belongs to an object and performs a specific task on that object.
Some Examples of Method are ;
name = "irfan"
print(name.upper())  #uppercase
print(name.lower())   #lowercase
print(name.capitalize()) #Capitalizes 
print(name.title())   #capitalizes first letter of every word in a string.
print(name.strip())  #removes spaces at the beginning and at the end.
