Modules are python files that contain reusable code such as functions , classes and variables.Modules make our tasks much easier because we don't have to write the same code for tasks everytime instead we can just import the modules.
We can import modules using the import keyword. An example is shown below :

import math 

print(math.sqrt(144))

Output : 12.0

This imports a math module that has code for functions and tools in it for tasks related to math.
