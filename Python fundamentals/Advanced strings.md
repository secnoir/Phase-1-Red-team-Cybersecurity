

Advanced string operations lets us manipulate and work with strings more efficiently.

Important methods and operations:

+            # Joins two strings together.
*            # Repeats a string multiple times.
.upper()     # Converts all characters to uppercase.
.lower()     # Converts all characters to lowercase.
.title()     # Capitalizes the first letter of each word.
.replace()   # Replaces part of a string with another string.
.split()     # Splits a string into a list.
.join()      # Joins a list of strings into one string.
.strip()     # Removes spaces from the beginning and end.
.find()      # Finds the position of a word or character.
in           # Checks if a word or character exist in a string.
f""          # Inserts variables into a string.

Example:
name = "irfan"
print(f"Hello {name.upper()}")

Output:
Hello IRFAN
