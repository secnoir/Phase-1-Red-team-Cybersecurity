
A string is a sequence of characters or text that are inside quotes which can be single , double or triple quotes.
Numbers can be strings too if they are inside quotes such as 
"123" .
In strings you can use both single and double quotes , they are both valid.
Lets say we want to print a string we can do : 
print("Hello, World!")
This prints Hello, World!
There is also a thing called Multi-line string , it basically prints a string in multiple lines , We need to use triple quotes for multi line strings. An example of multi line string is : 
print("""This is a Multi line 
string. """)

Output :
This is a Multi line 
string 

we can also use multi line string from a variable.
