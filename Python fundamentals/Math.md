for mathematical calculations in python we use arithmetic operators , those arithmetic operators are :
print(50 + 50) #Addition
print(50 - 50) #Subtraction
print(50 / 50) #Division - returns a float
print(50 * 50) #Multiplication
print(50 + 50 - 50 * 50 / 50) #PEMDAS/BODMAS 
print(50 ** 2) #Exponents - (power)
print(50 % 6) #Modulus - returns the remainder
print(50 / 6) #Division - returns a float 
print(50 // 6) #Floor - division (removes the decimal part)
