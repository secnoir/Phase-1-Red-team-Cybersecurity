A boolean expression is an expression that gives either True or False as an answer.
Example :

numb = 10 > 3 

print(numb)

Output : True

Relational operators :

It is used to compare two values. These operators are :

equal to : == 

not equal : !=

less than : <

greater than : >

greater or equal than : >=

less or equal than : <=

Example : 

less_than = 6<4

print(less_than)

Output : False

Boolean operators :

They are used to combine or change boolean expressions.

The three boolean operators are (and) , (or) , (not)

Example :

number = 10 > 6 and 4<10   #True

print(number)

Output : True
