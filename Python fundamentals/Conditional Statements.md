Conditional Statements are the statements (if , if-else, if-elif-else) that allow a program to make decisions. it basically checks whether a condition is true or false and then runs the appropriate code.
The three conditional statements are :
1.if
2.if - else
3.if - elif - else

Example :
def check_score(score):
    if score >= 60:
      return "You passed the exam!"
    else:
      return "You have failed the exam."
