ARP stands for address resolution protocol , its main job is to resolve an ip address  to a mac address. ARP is only used locally. When a device wants to send data to another device on the same LAN it needs the mac address of that device and ARP solves this problem. ARP first checks its cache to see if it has the mac address to that ip , if it doesn't have the mac address it sends an ARP request (broadcast) that says who has ip 192.168.x.x and the device with that ip replies with its mac address and ARP caches it for next time.Now that we get the destination mac address we can send the ethernet frame to the correct device.
