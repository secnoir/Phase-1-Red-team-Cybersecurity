
TCP/IP is a practical model of how data moves between devices on a network. It has only 4 layers compared to OSI model which has 7 layers.
The 4 layers are :

LAYER 4 : APPLICATION  (Application + presentation + session) 
LAYER 3 : TRANSPORT  
LAYER 2 : INTERNET      
LAYER 1 : NETWORK ACCESS  (Data link + Physical)

TCP/IP combines layer 7(Application) , 6(Presentation) and 5(Session) into a single layer (layer 4 Application). It also combines layer 2(Data link) and layer 1(Physical) into one layer (layer 1  Network Access) .
