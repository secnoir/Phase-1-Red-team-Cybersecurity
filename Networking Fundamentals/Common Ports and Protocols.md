Some common ports and protocols are :

 TCP :            
 * FTP(21)
 * SSH(22)
 * TELNET(23)
 * SMTP(25)
 * DNS(53)
 * HTTP (80) / HTTPS(443)
 * POP3(110)
 * SMB(139 + 445)
 * IMAP(143)

UDP:
* DNS(53)
* DHCP(67 , 68)
* TFTP(69)
* SNMP(161)

What are Ports : 
Ports are the communication endpoints which tells the system what application or service should recieve incoming traffic.Without ports incoming traffics wouldn't know where to go and it would be a mess. 

What is a protocol :
A protocol is basically a set of rules that devices follow to communicate with each other.It is important because without it devices can't communicate with each other properly.
