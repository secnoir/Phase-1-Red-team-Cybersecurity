OSI stands for open system interconnection , it is a theoretical model of how data moves between devices on a network from start to finish.
It consists of 7 layers which are :
LAYER 7 : APPLICATION            -> HTTP , SSH , FTP , SMTP etc.
LAYER 6 : PRESENTATION     ->  encryption TLS/SSL
LAYER 5 : SESSION               ->    manages , Establishes and ends sessions.
LAYER 4 : TRANSPORT       ->    TCP/UDP. 
LAYER 3 : NETWORK           ->    IP Addressing , routers.
LAYER 2 : DATA LINK           ->    MAC addressing , ethernet frames , Switches
LAYER 1 : PHYSICAL              ->    Cables , Fibres-optics , Hubs , Wifi.

This is just a theoretical model used to understand how data moves between devices in a network , the TCP/IP is a practical model.
