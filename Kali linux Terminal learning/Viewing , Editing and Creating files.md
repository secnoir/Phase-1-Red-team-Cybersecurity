This is for learning how to create , edit and view files.

echo -> this is used to create a file and put text directly as you create the file. Example : echo “hi bro” > chat.txt

That command created a file chat.txt and inside it is the text ( hi bro )

if we put something again like echo “hey” > chat.txt , it overrites the existing text so if we want to append new text while keeping the old text we use echo “hey” >> chat.txt , here we used double ( > ) to append new text.

touch -> this is also a command that is used to create a file , it differs from echo because it creates an empty file unlike echo where you can put text when you create the file.

nano -> this is a tool used to edit files , when you create a file using touch command it is empty so you can use the nano tool to write in that empty file. In simple words nano is a text editor.

gedit -> this is a similar tool to nano but it is a gui tool.
